# BlindNav - AI 盲人导航助手

> 一个面向视障用户的 Android 室外导航辅助 App，通过手机摄像头实时识别盲道、斑马线、人行红绿灯和物品，用语音播报引导行走。

---

## 关于这个项目

**这个项目主要是由 AI 辅助完成的。** 我本人不会编程，完全是靠 AI 一行行写出来的，所以代码写得比较稀烂，还有很多不完善的地方，请多多包涵。

**本项目已经停止维护。** 最后的更新停留在 2026 年 7 月左右。目前精力已经投入到下一代的研发中，这个项目就开源出来，供有需要的人参考。

---

## 项目来源

这个项目的灵感来自于 YouTube 上看到的 **OpenGlass** 导航眼镜项目（`OpenAIglasses_for_Navigation`）。我看到那个项目后，觉得很有意思，就想能不能把它转换成普通人更容易接触到的形式——一个 Android App，直接用手机就能用，不用买专门的眼镜硬件。

项目初期参考了 OpenGlass 项目的思路和部分模型权重。后续的红绿灯分类模型是我自己训练的。

---

## 功能特性

- **盲道导航**：实时识别盲道区域，语音提示直行、左移、右移
- **斑马线检测**：识别斑马线并判断距离阶段，引导对准
- **过马路辅助**：独立状态机，自动寻找斑马线、等待绿灯、引导通行
- **红绿灯检测**：识别人行横道红绿灯，语音播报红灯/绿灯
- **物品查找**：支持 601 类商品识别，语音引导寻找物品
- **障碍物检测**：通用障碍物检测（当前版本未默认启用）

## 技术栈

- **语言**：Kotlin
- **UI**：Jetpack Compose
- **相机**：CameraX 1.3.1
- **推理引擎**：ONNX Runtime Android 1.16.3
- **AI 模型**：YOLOv8-seg（分割）、ResNet18 / LYTNetV2（红绿灯分类）、YOLOv8（商品识别）

---

## 模型说明

⚠️ **重要提示**：仓库里的模型都是**最原始的版本，没有经过任何优化**。

### 分割模型
- 来源：基于 YOLOv8x-seg 转换
- 用途：盲道 + 斑马线分割识别
- 大小：约 274MB（FP32）

### 红绿灯模型
- **ResNet18**：我自行训练，用于识别人行横道红绿灯
  - 绿灯准确率还行，大约 90%+
  - 红灯准确率偏低一些，大约 90%
  - **没有专门针对汽车红绿灯做误报优化**，所以在实际使用中可能会有误报
- **LYTNetV2**：另一个轻量级模型，仅区分红/绿两态，准确率约 96.6%

### 商品识别模型
- 基于 YOLOv8，支持 601 类商品识别
- 大小：约 38MB（FP16）

## 已知限制

1. **代码质量**：由非专业开发者借助 AI 完成，代码结构和优化都很粗糙
2. **模型性能**：模型都是原始版本，未做量化、剪枝或针对移动端优化
3. **红绿灯准确率**：红灯检测准确率偏低，且没有过滤汽车红绿灯，存在误报
4. **设备适配**：只在 realme 手机（骁龙 660）上测试过，其他设备表现未知
5. **推理速度**：冷启动较慢，分割模型加载约 10-12 秒
6. **盲道覆盖**：目前只支持纵向盲道，横向盲道无法处理

## 如何使用

### 环境要求
- Android Studio
- Android SDK（建议 API 29+）
- 支持 CameraX 的 Android 设备

### 快速开始

1. 克隆仓库
```bash
git clone https://github.com/你的用户名/blindnav-android.git
```

2. 用 Android Studio 打开项目

3. 同步 Gradle 依赖

4. 连接真机运行（建议使用带广角摄像头的手机）

### 模型下载

模型文件托管在 Hugging Face，首次运行前请先下载：

```bash
# 使用 Hugging Face CLI
huggingface-cli download tianzi41/BlindNav --repo-type model --local-dir ./assets
```

或者直接访问：https://huggingface.co/tianzi41/BlindNav

将下载的 `models`、`voice`、`music` 文件夹复制到 `app/src/main/assets/` 目录下。
